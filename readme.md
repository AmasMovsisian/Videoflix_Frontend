# Videoflix Frontend Project

![Videoflix Logo](assets/icons/logo_icon.svg)

This repository contains the frontend for the **Videoflix** streaming platform.

The frontend was **provided by the Developer Akademie** as part of the curriculum and serves as the client application for the Videoflix backend project. My task was to connect this frontend to my self-developed Django REST backend and implement the required backend functionality.

## Purpose

The project is intended for educational purposes and demonstrates the integration of a predefined frontend with a custom backend implementation.

## Technologies

- HTML
- CSS
- JavaScript (Vanilla)
- HLS Video Streaming
- JWT Authentication (HttpOnly Cookies)

## Backend

The frontend communicates with a separate Django REST API that handles:

- User authentication
- Email activation
- Password reset
- Video streaming
- HLS playlists
- JWT authentication
